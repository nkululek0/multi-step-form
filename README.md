# Multi-Step Form

This project implements a multi-step form using React, TypeScript, and Vite.

## Key Features & Benefits

*   **React-based:** Leverages the React framework for a component-based architecture.
*   **TypeScript:** Utilizes TypeScript for enhanced type safety and code maintainability.
*   **Vite:** Employs Vite for fast development and build times.
*   **Multi-Step Form Logic:** Provides a structured approach to break down complex forms into manageable steps.
*   **Clean UI:** Offers a simple and intuitive user interface.

## Prerequisites & Dependencies

Before you begin, ensure you have the following installed:

*   **Node.js:** (v18 or higher)  Download from: [https://nodejs.org/](https://nodejs.org/)
*   **npm:** (usually installed with Node.js) or **yarn:** (optional, but recommended: `npm install -g yarn`)

## Installation & Setup Instructions

Follow these steps to get the project up and running:

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/nkululek0/multi-step-form.git
    cd multi-step-form
    ```

2.  **Install dependencies:**

    Using npm:

    ```bash
    npm install
    ```

    or using yarn:

    ```bash
    yarn install
    ```

3.  **Start the development server:**

    Using npm:

    ```bash
    npm run dev
    ```

    or using yarn:

    ```bash
    yarn dev
    ```

    This will start the Vite development server. Open your browser and navigate to the address provided (usually `http://localhost:5173`).

## Usage Examples & API Documentation

Currently, there is no formal API exposed. The project's functionality is primarily focused on the multi-step form UI. Please refer to the code in `src/app/App.tsx` and the surrounding files for examples of how the form is implemented.
